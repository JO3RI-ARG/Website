Payments and newsletters 

November 21, 2026

For now, we decided to use the free plan at MailerLite. A clean and simple solution, and probably not the only one out there. If we would like to do that also on our own, we would need a server, because Github, only serves static pages (it can't collect data, like email addresses, it can only serve a website).  As an IT manager I used to run the companies own mailserver ... for a while and then sourced everything out (10 years ago) to Google Docs (I didn't like Microsoft, I even had Debian servers host the Active Directory). So I know that running your own mailserver is a PITA. Why? Because of spam rules, random attacks and uptime.

And then we have the payments, well again, doing this yourself, might even not be possible, because of the complexity in security and connectivity with bank payment systems. Not many options there, Stripe and PayPal. You can add PayPal into Stripe, but you have to change your account into a business account and we're not sure about that yet. So for now, 2 separate buttons.

GOOGLE is collecting data?

November 20, 2026

Our site is up and running ... Hurray ! fancy layout, nice fonts, ... But wait ... what? Google collects data if you use google fonts, java scripts and whatever you use on your website to make it fancy and good looking.

That is not what we want, so next question for the AI, sift through our website and figure out every thing that gathers our visitors data. we cleared it all out, downloaded fonts, removed all links to external plugins and even old Weebly stuff that was still in.

Now our website is clean, nothing is gathered, nothing leaves the site. We do need a mailer option, so you can directed to Mailerlite to subscribe. And we need payment buttons with Stripe (and PayPal). But no hidden, behind your back, collecting your data.

We have an editor, now we need content

November 17, 2026

The editor is ready, but how do we get the content to our new platform and where do we host it? Github to the rescue!  Github works perfectly for a static website (and that's all we need). We already have a paid domain name, so pointing the DNS to Github isn't that hard. But what about the content? It seems that you can export your Weebly site as a html page and folder with images. You loose the ability to layout the site (that's what made Weebly powerful). 

So we downloaded and asked AI to help improve the editor to have a Weebly feel, sort of, kind of. Not a one on one copy, but dragging importing images, optimizing images, adding pages, ... And it all worked out. The website looked exactly as it was on Weebly and we were able to update text and pictures and do lay-outing.

Weebly is solded, now what?

November 15, 2026

So, suddenly Weebly seems to be sold and it isn't sure if the free version will stay available. What now? Find an alternative? We found out that the original creators tried to buy Weebly back (not the same people as the ones that sold it). Articulation it is called. I you want to find out more, ask your (free) AI.

So an alternative ... again with a free limited plan ... and the possibility it changes, free plan get's ditched ... Why not build are own Website Editor? And why losing time doing it myself? I asked Claude and voila, our own Website Editor. With every change on our website, we also look at improving the editor.
